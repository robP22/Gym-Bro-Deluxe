# Gym-Bro-Deluxe
A tool that calculates estimated effort needed for the desired lift type, weight based on the users body data.
It will include functionality that includes:
  choosing a workout template or creating a new one
  choosing the day to initialize the workout (so that the workout aligns with the realtime calendar schedule of the user)
  shows the user how to perform the workouts safely and suggests a lift weight based on the plan or the lift_intensity slider
  tracks progress and allows the user to accurately record repititions at specific weights (can possibly use this as a prediction for how many reps the program suggests for each workout)
